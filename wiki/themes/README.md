# Themes

Cross-cutting concepts that appear in 2+ articles with real substance.

Create a theme page when:
- A concept is referenced in 2+ articles, and
- Readers would benefit from a canonical explanation the articles link to, and
- The concept doesn't fit neatly into any single topic series.

Candidate themes (populate as the site grows):

- `react-pattern` — Reasoning + Acting loop. Spans agents.
- `hallucinations` — Cuts across grounding, evaluation, ai-ux.
- `rag` — Touches grounding, context-windows, agents.
- `tool-use-reliability` — agents, evaluation.
- `hitl` — Human-in-the-loop. ai-ux, agents, grounding.
- `cost-reliability-tradeoff` — cost-latency, agents, evaluation.

See [`../SCHEMA.md`](../SCHEMA.md) for the theme frontmatter and section layout.
