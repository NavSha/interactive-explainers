## What it is

"Reasoning + Acting" — an agent architecture where the model alternates between thinking steps (reasoning about what to do) and action steps (calling tools or producing output). Published by Yao et al. (2022). The dominant mental model for how modern AI agents work, and the pattern underlying tools like Claude Code.
